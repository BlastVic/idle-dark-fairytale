# Spine 特效测试场景

打开 `Assets/Tests/SpineEffects/SpineEffectsTest.unity` 后运行。也可使用 Unity 菜单 `Tools > Dark Fairytale > Effects > Open Test Scene`。

目前共 12 项：原有 EmberBolt（火球）、EmberImpact（命中爆炸）、ClawArc（爪击）、AshDust（扬尘）、EmberBreath（火焰爆发），以及受击（原版）、荆棘格挡、回旋镰斩、灰叶治疗、残翼复生、裂隙雷霆、蜡封护佑 7 种通用战斗粒子。全部直接引用正式战斗使用的 Prefab 和材质。

- 顶部按钮选择特效；切换会清理上一只。
- 重播、暂停/继续、循环开关；每次循环末尾留 0.35 秒。
- 时间轴拖动会暂停并定位；步进每次 1/30 秒。
- 特效大小范围 25%–200%，默认 100%，按各特效与角色的适合比例预设；调整不会修改正式战斗资源。
- 播放速度 0.1–2 倍；支持战斗背景和深色纯色背景。
- 宽度按完整动作的联合包围盒计算（粒子按可见粒子位置和尺寸测量），不会随当前帧忽大忽小。

场景包含小红帽与 MobTallowkin 敌人的待机展示。受击、命中爆炸和爪击定位到敌人身体；扬尘与群攻定位到敌人脚下；雷电在敌人上方；格挡、治疗、复生、吸收定位到小红帽身体。火球从小红帽一侧向敌人飞行，仅用于位置预览，不模拟真实宠物施法或伤害。

`SpineEffectsTestRig.prefab` 内含可编辑 UGUI、小红帽与敌人 Spine 节点、相机、背景及十二个资源引用；可在 Inspector 调整。构建入口只在缺失时创建，不在导入或运行时重建 UI，不覆盖已有 Prefab。

验收命令：编辑模式下写入 `validate` 至 `output/spine-effects-test/command.request`。结果与实际 Unity 截图仅保存在该忽略目录。验证选择、播放、暂停、步进、尺寸、背景开关以及 9:16、3:4、1:2 三比例。

通用贴图的设计说明、生成提示词与参数变更见 `ArtDirection/Effects/Common/`。通用粒子预览为固定随机种子，可暂停、拖动和步进；预览实例暂停销毁计时器，正式战斗的销毁机制不受影响。

受击（原版）在 100% 大小时保留原 Prefab 根缩放、子粒子缩放及原图层，不再使用统一包围盒归一化；摆放到敌人身上的位置仍属于测试场景布局。

灰叶治疗使用 caiwenji_skill_beaten_2 原始 Spine 动画，约 1.13 秒，仍通过 Heal_Particle 触发。正式与预览共用根缩放 4.0 和脚底原点；100% 不按包围盒调整。测试角色采用 DarkFairytaleBattleStyle 的尺寸规则，镜头可见高度对应战斗相机 z=-15、FOV=66°。

通用特效尺寸以原版受击和角色比例为基准：格挡覆盖身体，群攻位于敌方脚下，复生展开双翼，雷电从敌人上方落下，护佑采用单枚大蜡封。7 项通用特效均直接使用正式 Prefab 的尺寸与定位规则，100% 不再包围盒归一化。

残翼复生：0–0.4 秒展开至最大；0.4–1.3 秒保持最大尺寸上移；1.3–2.0 秒继续缓慢上移并淡出。正式与预览共用 ParticleSystem 的尺寸、速度和透明度曲线，支持拖动时间轴与单步。
