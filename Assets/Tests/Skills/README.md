# 技能测试室

打开 `Assets/Tests/Skills/SkillTest.unity`，点击 Unity Play。也可使用菜单 `Tools > Dark Fairytale > Skills > Open Skill Test Scene`。

- 点击顶部“全部技能 +”展开 15 个技能，选择后自动收起；用 + / − 调整 1–10 级，点击“测试 / 释放”。
- UI 与 MonsterAnimationTest、RedHoodAnimationTest 统一：深色面板、米白文字、金棕细线、暗红选中态及同一套禁用反馈。展开/收起有短渐变，收起后不阻挡战斗区点击。
- “循环”重复测试当前技能；“普通攻击”用于比较增益前后伤害。
- 技能可累计启用，例如先启用兽群领袖，再测试幽灵狼群。点击“重置场地”清空已启用技能、召唤物和统计。
- 三个怪物保留正式受击动画、音效、伤害数字与特效，不显示血条，不消耗生命，不死亡。命中统计记录经过防御与暴击处理后的伤害。
- 雷电测试的靶怪始终满足半血条件。首领猎手将一个靶怪设为首领。回旋镰斩、狼群和雷电共用正式动作队列，可连续选择并加入队列。
- 回血会先降低角色生命；复生和护佑会强制通过概率判定以便反复观察。击杀类技能模拟击杀事件，靶怪不死亡、不掉落、不实际增加经验。属性类技能应用正式属性计算。这里验证效果，不用于测量自然触发概率。
- 场景独立启动，直接使用已保存的小红帽、3 个靶怪、预览背景和战斗服务；不加载 Gameplay、主界面、营地、教程、序章、关卡流程或 SaveManager。退出 Play 后测试数据丢弃。
- 技能伤害、动作队列、音效、召唤和特效复用正式实现；场景独立性不靠隐藏主界面实现。

UI 是 `SkillTestHUD.prefab` 的持久化 UGUI 节点，可以直接调整布局、文本和按钮。创建工具只在明确执行且场景不存在时创建，不会自动覆盖已有场景或 Prefab。小红帽和三个怪物是场景中持久化的正式 Prefab 实例，打开场景即可查看。SkillTestStage 绑定这些实例，直接引用正式 `BattleStyle.asset` 的站位与尺寸，相机投影与 Gameplay 战斗相机一致。窗口比例变化按场景 targets 数组顺序重新摆放，不使用无序目标集合。技能名称和数值标签以纯数据保存，不引用正式技能界面 Prefab。

验证入口为 `SkillTestValidation`，记录与 Unity 实际截图保留于已忽略的 `output/skill-test/`，不提交游戏截图。测试场景不加入正式 Build Settings。
