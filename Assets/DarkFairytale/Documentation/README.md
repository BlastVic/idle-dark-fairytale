# Dark Fairytale 正式资源目录

- Characters：正式角色；小红帽见 `Characters/RedHood/Documentation/README.md`。
- Monsters / Companions：怪物与伙伴。
- Battle/Settings：战斗布局配置 `BattleStyle.asset`。
- Environment：章节背景、环境 Prefab 与环境动画。
- Effects：正式特效；公共阴影与光晕在 `Effects/Shared/Textures`。
- UI：按功能页面组织，再分 Prefabs、Materials、Shaders、Textures、Sprites、Data 等。
- Documentation：目录说明。

以上路径相对于 `Assets/DarkFairytale`。制作原稿归入 `Assets/ArtSources`，不能成为运行依赖。完整目录规范见 `Docs/Production/ProjectStructure.md`。
