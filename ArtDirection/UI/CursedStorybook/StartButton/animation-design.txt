开始按钮 Spine 动画设计 — 血色书签
2026-10-14
交付阶段：动画设计/关键帧方案，尚未生成可运行的 Spine 骨骼或替换游戏 Prefab。
美术基准：Shelter/Reference/ApprovedHome.png 底部继续战斗按钮。
保留暗红纸面、荆棘金边、森林剪影、镰刀和新月蜡封；方案演示文字为“开始冒险”，落地时沿用实际按钮文案。无古神符号或剧情暗示。

idle（小写，循环，3.20 秒）
0.00s / 3.20s：同一静息姿势，保证无缝循环。
0.80s：左右纸角相位错开轻抬，最大 2px（以按钮约 823x126 为基准），蜡封挂带轻摆。
1.60s：纸角回落；蜡封新月暖金反光缓慢达到峰值，亮度增幅不超过约 12%，无整体闪烁。
2.40s：反光淡出，挂带回摆。挂带角度不超过 +/-1.5 度。
主体不整体缩放或漂移，文字始终稳定。微尘仅作可选分层，至多 2–3 粒，不能遮挡文字。

pushdown（小写，非循环，0.18 秒，结束保持）
0.00s：从当前 idle 混合进入，禁止首帧跳变。
0.08s：主体下移 4px，宽度 99%，高度 95%；蜡封下沉 3px，纸角向内收 2px；阴影缩短，底色略暗。
0.18s：轻微回稳至宽 99.5%、高 96.5%、下移 3px，保持按下状态，不自动弹回。
细荆棘边缘随纸面向内收，不生长刺向文字。镰刀最多偏转 2 度。
文字独立，随整体下移但不非等比压缩；保持字号、可读性。
松开：以 0.12 秒混合回 idle，无第三个命名动画。
有效抬起才触发原按钮动作；移出/取消只恢复 idle，不触发导航。
禁止 Spine 事件和 UGUI onClick 各自重复触发进入。

建议骨骼与图层
root 固定命中区（动画不改变 UGUI RectTransform 热区）
  body（纸面、边框、森林剪影）
    left_edge / right_edge（边角轻微形变）
    scythe（独立装饰）
    seal（蜡封）
      ribbon_l / ribbon_r（挂带）
  shadow（独立阴影）
  glint（低强度蜡封反光）
  text_anchor（挂载真实 UGUI 文本，不将字烘焙进贴图）
建议 9–12 根骨骼；边角少量网格顶点即可。SkeletonGraphic 禁止射线，外层 Button 统一交互。
现有项目 Spine runtime 为 3.8，落地导出须兼容 3.8；本方案不含未经验证的 .spine 文件。
保留外层可编辑 UGUI Prefab。避免现有 ShelterButtonFeedback 与 Spine 同时缩放造成双重反馈。
禁用时停止动画并整体灰化底图、边框、图标、文字，恢复时进入 idle；时间使用 unscaledTime。
落地验收：9:16 / 3:4 / 1:2 Unity 实景、长按保持、拖出取消、快速连点、禁用恢复、菜单切换后动画复位。
