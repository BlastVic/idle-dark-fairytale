战斗 UI 改版示意 — 2026-10-14
阶段：基于本地实际 Unity 截图的视觉设计示意，尚未替换游戏 UI，也不是改版后的 Unity 验收截图。
基底：output/combat-float/battle-1080x1920.png。
目标：提升生命信息辨识度，简化装饰，与现有全屏纸页/暗红书签界面统一。
顶部：统一窄纸页信息带，左侧暗红返回书签，中间波次及菱形进度。
玩家：底部紧凑书页面板，头像+等级；生命名称、粗体具体数值单独置于血槽上方；厚实暗红生命槽；经验作为次级信息。
怪物：脚下简洁粗血槽、深色空槽、轻金属描边；数值置于槽内。风格接近传统游戏血条的直接表达，非宣称复用原版美术。
示意数据与原截图一致：第1/3波，玩家Lv.1，12/14生命，0%经验，怪物1/3生命。
后续制作：所有文本与进度值使用真实 UGUI 组件，持久化可编辑 Prefab；复用确认素材；9:16 / 3:4 / 1:2安全区与战斗点击区验证。示意图不可作为已完成实机实现的证明。

v2：生命和经验统一上方左名称/右数值，下方等长进度条；经验字号更小、槽高更小。
经验下增加单排技能状态示意：就绪、冷却倒计时、效果生效时长。仅展示有时间状态的技能，常驻被动不强行占位；纯概率触发不虚构冷却。
v2 中技能图标与 8s/3s 为布局占位示例，未核定现有技能机制；落地须复用实际技能美术和真实运行时状态。

v3 用户修订：技能直接复用技能 UI 的原始 Sprite/材质，不新增替代图标。删除图标下方进度条和所有状态/秒数文字。
冷却表现：完整灰色遮罩开始，12点为起点，按顺时针逐渐揭开图标，完成一周后移除遮罩。遮罩与图标外形透明轮廓一致，禁止灰色矩形底。
新图为静态概念示意，生成图标仅作位置/遮罩效果说明，实际制作须引用现有 CleanSkill 资源，不以生成图截取替代原技能素材。

v4 用户修订：技能状态图标缩小至 v3 的约65%目标，不作为可点击按钮；保持原图与径向冷却遮罩，不增加下方文字/进度条。收紧头像、纵向间距及装饰留白，底部整体降低高度并保持贴底，释放战场空间。生命与经验仍等长对齐，生命数值优先。
