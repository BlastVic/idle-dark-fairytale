# 获得物品提示

采用灰旧纸页、荆棘细边、暗红提示字，与装备 UI 共用已批准的纸纹和边框素材。左侧显示实际奖励图标，品质色细条辅助区分；右侧为获得类型、物品名称、品质与主属性。属性点、技能点、经验使用对应图标和奖励文案，不显示装备品质。

可编辑资源：`Assets/DarkFairytale/UI/Notifications/StorybookItemToast.prefab`。所有图片和文本是持久化 UGUI 节点。默认设计尺寸 800×190，顶部间距与入场、停留、退场时间均可在 Inspector 调整。无按钮，无射线拦截。

沿用 GameplayCanvas.ShowItemPopUp / ItemPopUpEnded 和原奖励队列，连续奖励依次展示。仅负责展示，不重复发奖。切场景黑幕和书本演出期间暂停提示计时；使用非缩放时间，游戏暂停不会卡住提示队列。

编辑器创建工具只响应显式操作，不随导入或运行重建。旧提示对象在场景中停用。

实机截图与验证记录存于已忽略的 `output/item-toast/`，不提交游戏截图。

验证：21 项检查通过，无失败。保留 9:16、3:4、1:2 的 Unity 实景截图，并检查自动退场、队列顺序、非装备奖励文案、长英文名称、黑幕暂停与恢复。战斗实景也验证了真实掉落调用能显示新版提示。测试启用存档隔离。

# 升级提示与特效

`StorybookLevelUp.prefab` 与物品提示共用旧纸页、荆棘框。等级以暗色大字显示，标题与新增属性点为暗红色；两侧金色微光短暂上浮、扩散并消隐。所有微光也是可编辑的 UGUI 节点，不在运行时生成。默认停留约 2.5 秒，无交互、无射线阻挡。

接入原 GameManager.LevelUpEvent → GameplayCanvas.PlayLevelUp，保留原升级音效、奖励计算和存档逻辑。连续升级合并起止等级、属性点和每五级的技能点。物品通知在升级提示期间暂停显示与计时。旧 LevelUpParticle / LevelUpSpinner 停用。战斗、奖励和营地共用同一升级提示。

升级 UI 验证：25 项检查通过，0 项失败。三种比例保存 Unity 实景截图；验证真实升级入口、连续 8→11 级合并为 3 属性点及 1 技能点、奖励不重复发放、物品通知错峰、旧特效停用、战斗 HUD 等级立即同步。截图与日志仅保存在 `output/level-up/`。测试存档写入已隔离。

# 经验加成提醒

排查发现旧提醒由 GameplayCanvas 启用 5 秒后开始、每 50 秒检查，未限制地图/装备/技能界面，也没有单次运行频次控制。新版仅在庇护所空闲、完成穿戴引导、尚未开启经验加成时出现。引导、设置、每日领取、升级、物品提示和场景切换期间不显示。

`StorybookExperienceReminder.prefab` 为可编辑 UGUI 纸页提示，提供查看/关闭按钮与按压反馈，8 秒自动消失；每次运行最多一次，使用 Storybook.ExperienceReminder.LastShownUtc 保留 4 小时跨次冷却。关闭及切换页面释放射线阻挡；提示纸面不拦截点击，只保留两个按钮的有效点击区域。

“查看”沿用新版经验页的淡入淡出路由，不扣费、不播放广告、不自动开启加成。实际加成仍为 +33%，每次 10 分钟。

经验提醒验证：20 项通过，0 项失败。9:16、3:4、1:2 保存实机截图并验证按钮射线、关闭不再重复、加成生效/地图/设置时抑制、超时消失、查看按钮跳转且不扣费。截图位于 `output/experience-reminder/`，玩家存档写入隔离。美术复查已移除按钮素材中心的旧烘焙文字，使用独立底色与真实文本。
