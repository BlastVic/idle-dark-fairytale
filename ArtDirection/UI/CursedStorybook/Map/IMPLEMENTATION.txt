第一章地图 UI 实装说明

验收基准：map-v2-top-down.png。顶部俯视地图，不出现天空、地平线或远近缩放。
本次范围：主菜单第 4 个「地图」入口，仅展示第一章黑森林及五个现有关卡节点。
第二章村庄和旧地图的后续背景、节点、云层、相机附属界面已隐藏；旧资源和关卡数据仍保留。

可编辑入口
Assets/DarkFairytale/UI/Map/Prefabs/Chapter01Map.prefab
实际加载容器：Assets/Prefab/Addressable Prefabs/Packages/MapPackageAuto.prefab（Addressables key: MapPackage）。
Core_9x16 下分别是 MapViewport、Header、SelectedNodeCard、Navigation。
MapViewport/Chapter01Terrain 保存背景、RouteSegments 和五个节点。
图片、节点按钮、文字、路线点、徽章和导航都是持久化 UGUI 节点；名称、波次和状态用 Text 组件显示。
StorybookMapUI 负责原关卡数据绑定、选择、拖动误触保护、进入和现有导航；StorybookMapLayout 只负责适配。
手工调整直接编辑 Prefab。Tools/Dark Fairytale/UI/Build Chapter 01 Map (Explicit) 是初版制作工具，执行会重新生成这套地图 Prefab；不需要为了日常调 UI 执行它。没有导入/运行时自动重建。

节点与实际场景
1-1 暮色林缘 = Khorasan Ruins I
1-2 蘑菇森林 = Khorasan Ruins II
1-3 月下过桥 = test01
1-4 溪畔小屋 = test02
1-5 小屋内部 = Mount Zion
解锁条件和波次数读取原 Waveset，不改动存档键。黑森林底图地物分别对应林缘、蘑菇群、木桥和溪畔小屋；第五节点在同一小屋的屋顶区域，以狼徽章表示内部关卡。

适配与交互
核心设计 941×1672（约9:16），支持 3:4 至 1:2 和安全区，超出支持比例区域为黑色。
地图统一等比缩放，宽屏调整初始观察位置，不横向拉伸。地图可纵向拖动；点击右上角定位按钮或底部地图标签回到选中节点。
未解锁节点可查看但不能进入；拖动过程不触发节点选择或进入；进入中阻止重复点击。
按钮继承按下缩放反馈，进入按钮有可用、禁用状态。

素材与已记录差异
ApprovedMap.png 保存已选参考稿；Sprites 下从参考图截取原有边框、书签、图标、节点徽章，避免用相似图替代。
BlackForest.png 是依据参考图去除 UI 并补全地形的制作底图。按本次授权移除了右上方第二章村庄；补绘地表与原稿并非逐像素一致。
动态文字以真实字体重新排版，节点额外展示真实波次或未解锁提示；选中卡片额外显示波次。字形、抗锯齿和纸纹拼接存在与原稿的差异，不宣称100%逐像素还原。
后续新增章节时仍须用真实底图验证道路、河流、岸线和植被拼接；目前没有第二章底图的拼接验收。

本地验收
Assets/Editor/Validation/StorybookMapValidation.cs 通过明确请求执行实际 Gameplay 验收；测试期间关闭存档写入，进度夹具只在本次 Play 会话有效。
截图与详细日志：output/map-ui/，该目录被 Git 忽略。
测试命令：编辑器空闲且编译完成后创建 output/map-ui/validate.request。capture.request 只做三种比例截图与按钮命中检查。

2026-10-12 地图交互更新（用户明确要求）
- 标签统一居于徽章下方正中；未解锁节点的名称纸签及波次隐藏，保留锁定徽章。对应 Prefab 节点仍可手工编辑。
- 修正原稿徽章切片的矩形范围，去除标签移开后露出的纸页残边。
- Map Layout 的 positionPreferenceKey 按章保存底图纵向坐标。离开地图/进入战斗/应用暂停时写入 PlayerPrefs，重开恢复；比例变化时保持相同底图坐标并做边界限制。
- 首次点击其他节点只选择并更新详情，再次点击已选中的可用节点直接进入战斗。因此双击未选中节点同样能进入；锁定、拖动和重复导航保护仍生效。
- SelectedNodeCard/AnimatedContent 为持久化节点。StorybookMapCardMotion 控制内容淡入和上移，duration 默认 0.24 秒、riseDistance 默认 18，可在 Inspector 调整；卡片外框仍由适配组件定位。
- StorybookMapInteractionUpgrade 是明确执行的增量迁移工具，保留现有 Prefab 美术及布局节点；不在导入或运行时自动执行。
