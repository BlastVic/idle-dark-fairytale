装备 UI 实装与验收记录
日期：2026-10-13

交付
主界面：Assets/DarkFairytale/UI/Equipment/Prefabs/StorybookEquipment.prefab
装备格：Assets/DarkFairytale/UI/Equipment/Prefabs/EquipmentCell.prefab
Gameplay 场景已经绑定新界面。布局、边框、文字、按钮、滚动区域均为持久化 UGUI 节点，可在 Inspector 修改。
Tools/Dark Fairytale/UI/Build Equipment UI (Explicit) 是重新制作初版的显式操作，会覆盖本界面 Prefab；日常手动调整不要再次执行。运行、导入和进入 Play 不会自动重建。

适配
以 941×1672 为设计尺寸。四列装备网格吸收剩余纵向空间；角色属性展开时网格平滑缩短，收起时恢复。较宽屏幕对固定区域内容等比缩小，图标不横向拉伸；网格保持可滚动，展开后至少保留一整行。支持安全区及超出支持比例的黑色区域。
实际 Unity 渲染：941×1672（9:16 近似）、768×1024（3:4）、720×1440（1:2）。另外验证顶部与底部安全区。

交互
分类、网格选择、左右滑动及相邻装备切换、属性对比、排序、筛选、锁定、装备替换、分解确认和批量分解已接入原有数据。
每个分类保留当次运行中的滚动位置和选中项。装备和锁定项不能被批量分解。
属性加点遵循原版点数消耗与连续加点限制；按钮同步禁用和恢复。收起后的属性不拦截点击。
融合进度展示原有共享经验；底部导航及返回庇护所保留原流程。

验证
本地 output/equipment-ui/validation.txt 记录 Unity Play Mode 检查。验证包括三比例关键控件射线、收展中间状态、按下恢复、加点状态、九种属性滚动、换装不丢失或复制、锁定序列化、分解确认取消、批量保护、空分类和导航。
测试过程禁用存档写入，临时测试物品不会保存到玩家存档。

美术对照与差异
边框、纸页、分类和导航图标直接使用已选 equipment-v2 设计稿素材。文字和功能数字使用真实 Text 组件，纸底及边框按独立节点组合。
reference-data-9x16-*.png 为同分辨率的参考数据测试：等级20、背包24件、选中攻击18、已装备攻击12，并临时使用设计稿武器图进行布局核对。此测试图不代表正式装备美术已替换。
9x16-current-save.png 是真实存档渲染；三比例截图使用真实游戏装备图标与临时测试数据。
当前仍有明确差异：正式装备插画保留现有装备库，尚未完成设计稿中武器风格的批量重绘；原版无独立装备等级，格子显示真实主属性而非概念稿的 Lv；编号读取现有游戏配置；纸底采用原稿局部平铺，纹理位置及文字栅格化与概念图仍不同。不能据此宣称 100% 美术还原。

所有游戏与验证截图仅保存在已忽略的 output/equipment-ui/，不提交 Git。
