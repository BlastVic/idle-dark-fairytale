第一章结尾 · 室内环境拟音混音 v1

旁白基底：Chapter01EndingZh/v5，保留连贯留言版。未变速或改动旁白时间轴。
交付：chapter01-ending-mix.wav / .mp3（完整试听）；page01–page05-mix.wav / .mp3（整轨切段）；narration-stem.wav（旁白），ambience-and-foley-stem.wav（独立连续环境与拟音）。
字幕与旁白时间不变。未来接入时建议环境层独立连续播放，避免页加载时环境音短停。本次未改 Unity。

定位方法：核对 v5 独立逐字转写的关键词时间，并根据动作语义安排在词前或句后的短留白。cue-sheet.csv / .json 同时记载页内、全片起点和对应旁白关键词。
时间小数是可复现的编辑落点，不是毫秒级人工听审精度保证；自动识别弱音边界仍可能有数百毫秒误差。

声音安排：
柴火底层复用已批准的安静猎人小屋音轨，降低 6 dB 后贯穿五页，不在页边界重启；保留稀疏的木柴噼啪，没有持续火焰轰鸣。第一幅说完“炉火的噼啪声”后再加两处短促点缀。
第二幅“旧抽屉”前起拉开声；结尾“把纸抽了出来”配短纸声。
第三幅“那是一张地图”之后展开纸张；“轻轻铺平”后再配轻短纸声。
第四幅“尸体拖到屋外”配两下软重物与木地板摩擦，后一下更轻。
第五幅留给旁白悬念，仅保留低声房间底层，不对目光落在地图等非动作词机械添加拟音。

抽屉、纸张、拖动声由 ElevenLabs 新生成，原始候选和配置留存 source/ 与 generation-config.json。source/cabin-loop.wav 与 fire-a.wav 来自现有猎人小屋音频，来源参见 ArtDirection/Audio/HunterCabin/sources.json。
拟音先控制尖锐瞬态，再设置音量。说话期间只将环境及拟音轻微压低，不压低旁白。全部 44.1 kHz / 16 bit 立体声，MP3 192 kbps。
validation.json 为技术检查；主观声效质感和旁白平衡仍待用户试听。
