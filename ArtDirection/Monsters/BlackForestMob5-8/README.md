## 后续制作边界

四套原资源均已有 Attack1、Death1、Hit、Idle1、Idle2、Idle3。正式制作要逐只沿用各自骨架与动画，并核对所有实际随机皮肤，不能只覆盖 Inspector 中显示的一套。

- 当前 Prefab 的 maxSkins：Mob5=6；Mob6/7/8=3。原资源的皮肤数量和运行时可选范围需在制作阶段分别验收。
- 蝙蝠主要为身体与两翼；蜘蛛包含多段腿和死亡序列附件。新分件必须覆盖动画实际使用的附件，避免死亡时露出旧风格。
- 原图来自 LegacyCatalog 的 Attack1 采样；正式分件应回到源附件与 UV 坐标制作，不直接裁剪概念稿当作生产贴图。
- 此轮没有 Unity 动画、变形或实景验收，不能据概念图宣称可直接导入。
