## 编辑与交付结构

- 五个可编辑 Prefab：`Assets/DarkFairytale/Environment/Chapter01/Node01` 至 `Node05/Environment.prefab`。背景为根 SpriteRenderer；Foreground 为独立前景，动画均为独立命名子节点，可以在 Inspector 调整位置、比例、排序和动画参数。
- 前景：林地近景遮挡、桥的近侧栏杆/桥腿、室内近景容器。第三节另拆远侧栏杆遮挡，避免水流盖住桥。第四节保留月亮前方树冠遮挡。
- Spine：同目录 `CH1_*` 下为骨架 JSON、图集、贴图、材质、SkeletonDataAsset，共十套新骨架；路灯复用已验证的 BF_Lantern 骨架，并按节点独立放置。
- 可重新导入 Spine 的源数据：`production/Spine/` 内的 JSON 与分件 PNG。当前交付是 Spine 3.8 JSON 工程交换/运行时格式，不是 Spine 编辑器原生 `.spine` 文件。
- 生成原始图与提示词：`production/*.png`、`prompts.json`、`revision-prompts.json`。

`Tools > Dark Fairytale > Environment > Build Chapter 01 Environments` 是显式的一次性重建工具；重建会覆盖本次生成的环境 Prefab 和骨架资源，手工调整后不要随意执行。运行游戏和资源导入不会触发重建。正式运行仅实例化保存好的 Prefab、适配镜头并播放动画。

## 动画规则

- 火光与烛火/炉火采用约 1.6 秒循环；祭祀火光为树后透出的光晕，不在空中放独立篝火。
- 小河采用 12×20 网格的四秒形变循环，叠加移动波纹，属于本轮 Spine 流动尝试；不是物理水体模拟。
- 瀑布水纹向下移动并淡出，约 2.5 秒一轮。
- 烟雾六秒上升、扩散、淡出。狼头阴影十八秒一轮，约第 7–8.8 秒穿过窗内裁剪区域。
- 月亮沿用已验证的睁眼/俯视/闭眼轨道，二十二秒一轮；运行时闭眼后选择普通或暗红眼周期。第三、第四节大小和高度保持一致，第三节月亮下移至波次标题下方，第四节同步调整。
