## 实景验证

使用 Unity Editor Gameplay、真实 Addressables 怪物与现有 HUD。在 Play 模式临时设置三怪测试波，检查结束后恢复编辑状态，不改写正式波次配置。菜单入口为 Tools → Dark Fairytale → UI → Validate Triangle Formation。

- 720×1280、768×1024、720×1440 三种实际 Game View 渲染均已检查；三怪完整位于战斗区域，前排绘制顺序高于后排。
- 角色与怪物采用待机姿势定格，保留完整三怪画面；验证工具处理了重新布局时出场动画透明首帧的问题。
- 首关胜利、返回营地、再次进入战斗、返回按钮回调、失败结算及失败后营地恢复均通过，运行错误为 0。
- 编辑器切换分辨率后的合成 GraphicRaycaster 检查在部分比例未命中；本次通过返回按钮实际回调验证流程，未将其表述为三比例物理点击均已验证。
