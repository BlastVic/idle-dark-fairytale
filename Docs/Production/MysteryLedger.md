## 验收方法

1. 按首次游玩顺序阅读，检查有没有过早出现“容器”“复制”等答案词。
2. 从揭晓倒推，检查先前证据是否真实成立，而非必须依赖新规则补洞。
3. 模拟无死亡、多死亡与漏看可选线索；关键真相仍应能理解。
4. 分开记录“玩家没有发现”“发现但解释错误”“揭晓后仍不理解”，分别调整可见度、引导或证据强度。
5. UI 名称、成就、加载提示、章节标题和配音字幕也要检查是否提前泄露身份。
