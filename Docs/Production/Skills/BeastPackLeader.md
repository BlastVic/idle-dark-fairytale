# 兽群领袖与书脊龙攻击调整

2026-10-17。

原“地狱吐息”改为被动技能“兽群领袖”，统一提高召唤：影狼、召唤：幽灵狼群和召唤：书脊龙的伤害。沿用原等级数列作为伤害加成：

| 等级 | 召唤伤害提升 |
| --- | --- |
| 1 | 4% |
| 2 | 8% |
| 3 | 12% |
| 4 | 16% |
| 5 | 20% |
| 6 | 24% |
| 7 | 28% |
| 8 | 32% |
| 9 | 36% |
| 10 | 44% |

统一倍率为 `1 + 加成`，仅作用于上述三种召唤。幽灵狼群的基础伤害和占用普攻时间的补偿一起乘倍率，每头狼仅应用一次；影狼和书脊龙在命中时读取倍率。其他主动技能、普通攻击不受影响。

前置条件、技能点消耗、技能树位置和既有图标保持原设置。枚举保留序号 15，存档继续读写 `breathOfHellLevel`，因此原投入等级直接迁移。Unity 字段通过 FormerlySerializedAs 兼容。

书脊龙每次选择攻击时固定 20% 使用爪击（Attack2），其余使用原单发火球（Attack1）。爪击不依赖兽群领袖或书脊龙等级，也不写入技能说明。五火球吐息（Attack3）的选择、特效发射及伤害入口已删除/禁用，正式 Prefab 已移除专用吐息特效引用；制作工具和测试场景的 Attack3 入口同步移除。骨架中保留原动画数据，未改动骨架或图集。
