# 施法队列与普攻损失补偿

2026-10-17：回旋镰斩、召唤：幽灵狼群、雷霆裁决统一接入 `PlayerSkillScheduler`。

## 调度规则

- FIFO：按请求进入顺序执行。普攻与施法都锁定主动画轨道，必须播放完整个动画，再经过原有 0.2 秒动作间隔，才取下一项。
- 同一技能最多保留一个未结束请求（含正在施放），防止重复计时或触发堆积。不同技能同时就绪均保留；同一攻击机会同时判定回旋镰斩与第三次攻击狼群时，依次入队回旋镰斩、狼群。
- 雷电冷却就绪时入队；已有动作不会被打断。雷电施法完整结束后重新计时。队列排空后才推进下一次常规攻击机会，队列中的技能不会再次触发整轮概率判定或递增三次攻击计数。
- 出队时重新校验等级及目标条件。无效请求直接跳过；没有可攻击敌人时清空队列。死亡、新战斗/营地初始化与胜利清空正在施放和等待中的技能。
- 每次施法只消费一次命中事件。混合退出动画的旧事件、错误动作的事件和提前完成调用均不能抢占当前动作。动画基类使用事件所属 TrackEntry 判断来源，不再把旧事件错误归属到当前动画。
- 首领技能仍按原规则触发，但同样受主动作锁保护；本次额外伤害补偿仅覆盖上述三个技能。

## 补偿公式

原技能的等级伤害保留，另增加一份普攻机会损失补偿。补偿在施法开始时计算并固定：

`补偿攻击次数 = (技能动画时长 / 攻速倍率 + 0.2秒) / (平均普攻动画时长 / 攻速倍率 + 0.2秒)`

`补偿总伤害 = 补偿攻击次数 × 单次普攻伤害基准`

平均普攻时长来自实际 Spine Attack1、Attack2，技能时长来自实际动画，不硬编码倍率。单次普攻基准包括攻击力与多敌人时的战场谋略增益；对不暴击的狼群和雷电，计入普攻暴击概率、暴伤的期望值。回旋镰斩的补偿随本次伤害正常暴击，不重复乘暴击期望。

这份补偿是**全次施法的总量**：回旋镰斩、雷电在命中时均分给当次有效目标；狼群均分到五次冲撞。基础技能伤害仍按各技能原规则计算。目标失效不会凭空补一次攻击，狼群伤害仍必须等实际冲过敌人前方才结算。

示例：攻速 100、无暴击、无战场谋略，以攻击力为 100%，普攻动画 1.18 秒：

| 技能 | 动画时长 | 单次施法补偿总量 | 1级实际基础与补偿 |
|---|---:|---:|---|
| 回旋镰斩 | 1.18秒 | 100% | 每名敌人基础100%，另将100%均分给本次目标 |
| 幽灵狼群 | 5.06秒 | 381.16% | 每次30% + 76.23%，五次合计约531.16% |
| 雷霆裁决 | 5.31秒 | 399.28% | 每名低于半血的敌人基础50%，另将399.28%均分给有效目标 |

防御、最低伤害、取整以及技能原有浮动在实际命中时处理，上表是扣防前的理论值。对不同防御目标的最终扣血不是严格相同的普攻替代。攻速变化会重新计算下一次施法的补偿。技能说明统一解释补偿规则，等级区域使用“基础冲撞伤害”“基础雷击伤害”，避免把固定基础数值误认为最终总伤害。

## 验证结果

实际 Unity 检查已通过，记录在 `output/skill-queue/validate.txt`：三种比例下三个技能连续 FIFO 施法；普攻、强制切换和提前完成均不能抢占动作；同时触发回旋镰斩和狼群均入队；同技能去重；过期命中不造成伤害；技能完整结束后解锁。三个技能的补偿公式在攻速 75、100、200 下核对一致。

独立伤害检查使用攻击力 100、零暴击、零防御和三名敌人：回旋镰斩合计 413（理论400，含±10%浮动）；狼群合计537（理论531.16，含浮动）；雷电按测试基础150%配置，合计849（理论849.28，取整）。验证了群攻补偿只发放一个总量，以及非暴击技能计入普攻暴击期望。无效雷电请求会跳过并播放后续狼群；死亡和胜利均清空队列。

技能详情采用持久化 Prefab，已检查三种比例下全部三个说明面板、基础数值与按钮可见性；运行战斗截图同样保留本地。本次未改变图标、纹理、特效缩放或其他美术资源。
