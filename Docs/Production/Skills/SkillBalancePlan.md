# 技能数值与成长统一方案 v1（2026-10-17）

这是基于当前代码、正式动画时长和技能点成本的第一轮平衡调整，已落地到配置与实现。公式评估不等于长期游玩验收；通关耗时、死亡率、技能选择率与不同装备阶段的实测仍需持续校准。

## 结论与原有问题

原数值不适合作为统一的正式平衡基线。

1. 影狼与书脊龙原本每击 150%～400% 攻击，且独立于角色出手。100% 攻速、无暴击/防御时，满级单只影狼约贡献 **272% 的原普攻 DPS**，书脊龙约 **277%**。这是叠加输出，不是替代普攻，远强于多数单项增益。
2. 回旋镰斩、复生、击杀回血、经验、首领技能、暴击护盾都把升级主要用在概率上，学习后不稳定且升级不改变单次反馈。
3. 经验技能满级必定双倍经验，等于全程 +100% 经验，进一步加速每 5 级获得技能点的循环，难以和战斗技能按相同点数比较。
4. 首领技能文案写“六连击、150%”，实际 Skill7 仅有一个 OnHit。当前改为一次强力镰击，不编造不存在的连击。
5. 护盾说明写 10%，实现固定 20%，AddAbsorb 忽略参数且反复叠加；生命/防御技能还存在未展示的格挡概率成长。现在去掉隐藏概率成长并修正护盾参数。
6. 技能施法会占用普攻时间。狼群与雷电实际播放还带1.2倍动作倍率，补偿计算现已计入，避免多补。只有看到“技能总伤害较大”不能判断收益，必须先扣除本来能打出的普攻。保留独立补偿项，并将首领技能也纳入队列和补偿。
7. 狼群的旧计算会让兽群领袖连同“普攻补偿”一起放大；现在只放大召唤本身伤害，防止补偿重复获益。

## 共用规则

- 保留 15 个技能、原技能 ID、旧存档等级、技能树前置关系和点数成本。等级 1～9 每级 1 点，9→10 消耗 2 点；满级共 11 点。
- 固定概率/固定频率写在说明中，不随等级改变。非概率型技能继续按原触发形式工作，不强行给每种技能增加随机性。
- 每项成长效果使用统一倍率：等级 1～10 为 **1 / 1.2 / 1.4 / 1.6 / 1.8 / 2 / 2.2 / 2.4 / 2.6 / 3**。10 级增加两档，对应 2 点成本。0 级效果为 0。
- 伤害型升级伤害；治疗型升级治疗比例；复生升级恢复量；护盾升级吸收量；经验升级额外经验；被动升级属性。
- 下面伤害均为角色攻击力百分比，治疗/护盾均为最大生命百分比。施法伤害不含额外普攻补偿。基础技能伤害不再把概率作为效果数值。
- 小红帽四种主动动作依次播放：回旋镰斩、幽灵狼群、雷霆裁决、猎王镰击。动画与起手特效保持现有制作。

## 典型收益估算

基准：100%攻速、无暴击、敌人无防御、无其他技能；普攻动画1.18秒+收招0.2秒，普攻DPS=攻击力/1.38。以下为单项技能的边际估算，不能直接相加成整套构筑结果。

| 技能 | 1级相对原普攻DPS的增加 | 10级增加 | 计算说明 |
|---|---:|---:|---|
| 影狼 | 约20% | 约61% | 单击/(1.2333+0.8秒)，独立于角色动作 |
| 书脊龙 | 约24% | 约73% | 80%×(1.5+0.3秒)+20%×(2.4667+0.3秒)的平均周期 |
| 回旋镰斩，1敌人 | 约10% | 约30% | 20%×基础伤害，普攻补偿抵消动作占用 |
| 回旋镰斩，3敌人 | 约30% | 约90% | 3目标累计；输出分散，不等于单体伤害 |
| 幽灵狼群 | 约12% | 约35% | 两次普攻+5.06/1.2秒施法及0.2秒收招，共7.18秒 |
| 猎王镰击 | 约11% | 约34% | 20%触发、Skill7时长1.65秒、补偿抵消延长的占用 |
| 雷霆裁决，1符合条件目标 | 约10% | 约31% | 6秒计时+5.31/1.2秒施法+收招，未含排队；只在残血阶段有收益 |
| 猩红契约，仅普攻 | 约9.6% | 约29.9% | 攻击与攻速相乘，0.2秒固定收招不会被攻速缩短 |

召唤物仍是可感知的强输出选择，但已从单只满级约2.7倍普攻DPS，降到约0.6～0.7倍；其固定攻击节奏不会随主角攻速加快，高攻速构筑中相对贡献降低。范围攻击在多敌人环境超过单体技能是有意保留的定位差异。

对混合构筑不能只加各行百分比：施法队列、残血条件、过量伤害、角色攻速、敌人防御、召唤物独立攻击都会影响真实收益。Boss技能实际概率是在普通攻击决策到达首领分支时计算，会受到优先技能占用影响。

## 后续调优边界

优先记录相同装备/属性下的单体Boss击杀时间、三敌清场时间、每分钟治疗/吸收量、每关复生次数、每分钟经验以及技能实际施放次数。至少覆盖低/中/高攻速和0/1/10级组合。没有全流程关卡与玩家数据前，不宣称所有技能已经达到最终平衡。

当前保留学习一级的明显收益，升级增量统一；技能点稀缺（升级每5级1点，另有融合奖励）下，玩家可以先扩展技能组合再重点升级。若实际出现“全部点1级永远优于专精”，应调整解锁/点数经济或成长曲线，而不是偷偷提高触发概率。
