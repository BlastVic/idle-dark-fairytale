# 技能测试场景与正式战斗一致性修复（2026-10-17）

## 原因与修复

- 测试场景曾复制 BattleStyle 并改高后排怪物位置。现在直接引用正式 `Assets/DarkFairytale/Battle/Settings/BattleStyle.asset`，删除独立副本，制作工具也不再生成副本。
- 测试相机原为正交投影，现在与 Gameplay 战斗相机一致：透视、66°、Z=-15。制作工具从正式相机读取参数，已有场景中保存相同参数。
- 窗口尺寸改变时，原逻辑遍历 HashSet 分配怪物站位，顺序不固定。现在使用场景持久化 targets 数组；布局后恢复待机，等角色动作结束再适配，避免清除正在播放的技能。
- 回旋镰斩的共用 AOE Spine 特效中，xg1 骨骼原始动画先右移再向左返回且逐渐升高，正式战斗同样受影响。CommonSpineBattleEffect 的 horizontalSweep 覆盖此骨骼的位移：保持高度，向右单向飞行，在原动画开始淡出前离开屏幕。保留旋转、美术尺寸、起手、烟尘和伤害逻辑。
- 正式 AOE Prefab 保存 horizontalSweep 开关；制作工具生成相同设置。预览采样与实际播放共用轨迹处理。

## 实景验证

`SkillStageValidation` 显式命令：`output/skill-stage-fix/command.request`，支持 `save-placement`、`test`、`production`。生产模式采用真实 Gameplay、关卡加载、技能动作与正式特效入口，编辑器测试期间禁止写存档。

通过 720×1280、768×1024、720×1440：

- 测试与正式场景引用同一个站位资产，使用同一相机投影。
- 以同一待机帧比较小红帽及三只指定怪物，四个角色在两种场景的屏幕坐标全部一致（容差 0.003 视口单位）。
- 每个场景实际施放回旋镰斩：逐帧验证水平位移单调向右、高度保持不变并出屏。
- 实际 Unity 待机与三阶段施法截图，以及坐标和检查报告，保存在已忽略的 `output/skill-stage-fix/`，不提交 Git。

注意：测试背景保留测试场景现有插画；正式关卡使用相应地图。布局与投影统一不要求两者使用同一背景图。
