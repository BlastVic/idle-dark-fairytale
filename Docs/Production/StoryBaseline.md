# 故事与表现基线

更新日期：2026-10-10。此处保存用户已明确的方向；候选细节另列，不能直接据此批量制作。进度见[开发总清单](../../DEVELOPMENT.md)。

## 已确认的核心

- 主角采用小红帽身份，不围绕祖母展开剧情；第一章狼外婆保留为 Boss，不是主角的亲属。
- 原始灵魂所属的人已经死亡。邪神利用同一精神/灵魂创造多个实验体，在精神世界里反复重塑，目标是培养适合降临的容器。
- 实验体同源却不是同一个独立生命；部分记忆相互关联，当前个体死亡不等于本人复活。
- 世界线性向前。尸体、遗物和指引可以积累，场所可以衰败；怪物被邪神复活不代表世界重置。
- 前代可杀死狼、继续深入并留下线索；后代仍可能遭遇复活的狼。不能写成所有前代都没通过第一章。
- 玩家先认为有人帮助自己，再认为线索由过去的自己留下，继而误信轮回；第四五章逐渐推翻，揭露多实验体与线性时间。
- 经常出现的数字是当前实验体编号。特定情况下增加，表达代际更替；范围、触发与显示位置仍待决策。
- 序章火祭红帽少女，主角只远远辨认红帽，不确认脸、不对视，然后逃入黑森林。
- 第一章以猎人小屋和狼 Boss 收尾；取得信息后必须回村庄寻找后续道路。
- 第二章村庄已焚毁并荒废。主角误以为离开期间遭怪物袭击，后期才认识到已有多代更替、很长时间过去。
- 第二章被人类怪物击败时，要与序章火祭产生呼应；如何在废墟状态重演待细化。
- 中后期出现大量小红帽遗骸与集中的坟场场景；具体历史与运尸机制待定。
- 前三章异常克制；第四五章明显精神错乱并揭露真相；第六七章童话与精神空间穿插、怪物抽象化；第八章抵达底层对抗投影。
- 最终 Boss 是邪神投影，邪神本体不可战胜。书中故事结束，但书外仍有更困难挑战。
- 结局书被合上，读者是后辈小红帽，阅读前辈的真实经历。她说“这个故事还是写得太温柔了，现实世界远比这残酷”，镜头拉远展示更怪诞的世界。

## 演出与制作约束

- 序章全程插画与旁白演出；正式章节开始、结束演出，中间实际游戏不播放插画与旁白。
- 八章：前七章每章五节，终章六节，共 41 节。序章另计。
- 同章节点视觉连续，章际以故事衔接为核心，不强求地理与视觉无缝。
- 英文旁白优先，目前试用 Lauren；已有音画样片是原型，不等于正式内容已验收或可直接商业发行。
- 角色与插画须遵循现有金发红帽与游戏绘画风格，避免写实电影风偏离游戏。
- 风声、村民声、火焰等用独立环境轨道表达；配音生成不自动等于完整声音设计。
- 失真效果可影响世界表现，不能破坏战斗/UI 可读性；具体强度和触发方案待定。
- UI、分辨率与截图规则以根目录 [AGENTS.md](../../AGENTS.md) 为准。

## 尚未确认的候选

“蔷薇城堡”“无底剧场”“记忆潮汐”“万我之境”等暂作工作名称。后三分之二的五节地点、敌人名单、Boss、编号腕部烙印、钥匙藏在第三块砖、桥门出口等，均为讨论中的候选细节。

不采用先前“整个世界重置，只有藏好的痕迹残留”的解释。也不把强制昏迷、未展示的固定死亡次数、击败投影自动停止全部怪物复活写成已确认事实。

## 仍需连接的设定

原有[童话书视觉文档](../../ArtDirection/Storybook/README.md)采用诅咒书、翻页主界面方向；现在又有后辈阅读纪实的结局。两者是否为同一本书、封面邪眼代表什么、记录由谁整理，需要 Q09 协调。保留已确认封面，暂不覆盖原文档。

现有黑森林有月亮睁眼动画，与“前三章异常不明显”的力度是否匹配，需要在第一章演出审查时判断；不要因为资产已存在就默认每节高频播放。
