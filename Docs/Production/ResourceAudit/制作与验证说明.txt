本轮范围：运行 UI 正式拆图、公共素材与边框、角色/怪物/伙伴/特效的纹理密度；保留现有功能、字体和已选图案。

1. 正式资源
- 通过 Unity AssetDatabase / PrefabUtility 修改持久化 Sprite、Prefab 和场景；保留原 Sprite GUID。运行时不重建这套界面。
- 原整张 UI 设计图的裁片转为独立透明图片；功能文字继续使用真实 Text/TMP。脚本中的隐藏状态图片一并迁移，包括地图锁定/可用、宝箱就绪和融合充能状态。
- 原稿和大图仍可作为制作参照存在工程中。是否入包取决于构建依赖，不以“工程里能找到”判断。旧完整框 Sprite 留给明确执行的制作工具，界面改用角/边资源。
- ProductionUiArtCatalog.json 记录来源、原矩形、处理方式、状态变体与边角资源。制作工具通过 ProductionUiArt 读取正式资源；只有明确的制作命令会修改 Prefab。
- UI/Production Paper 只处理干净纸纹的重复、纸面形状和颜色；正常灰化、裁剪容器、过场和光效材质保留。旧文字抠除、亮度抠图、矩形遮盖等运行修补已退出 UI 依赖。

2. 公共素材与九宫格
- 公共纸纹、红纸、导航、按钮及图标继续共享正式 Sprite；具体使用者见公共素材复用.csv。只合并相同内容，不把批准的不同图案强行统一。
- 3 个普通边框使用紧凑平铺素材；14 组带独特荆棘装饰的大框保存完整四角与四边，不用重复纹样替换独特画面。
- 这 14 组边框由 5,152,140 纹理像素缩为 713,074，减少 86.16%。RGBA32 像素量约从 19.65 MiB 变成 2.72 MiB；不是 APK 节省量。
- PanelFrameV3 还承担通知阴影。只对已验证为纯黑且中心完全不透明的实例使用纯色中心，保留相同边角、布局和 0.45 透明度。
- 边角为可编辑 UGUI 子节点，每组紧凑存储在三张纹理中，并保留 2 像素采样保护。这样减少无用中心像素，但会增加 Graphic 节点；未宣称真机 Draw Call 或 GPU 性能已优化。

3. 尺寸
- 血月结晶 819×700 → 256×219；引导箭头 619×1405 → 141×320。保留源图，以预乘透明度的面积采样生成正式贴图；布局未改。
- 角色、怪物、伙伴及特效共 112 组“资源/纹理/屏幕规格”测量，含 4 个屏幕规格和各动画 65 个采样点。普通粒子也纳入，未跳过。
- 密度为屏幕像素/纹理像素，值越高代表放大越多。大图集不代表单个部件有过多像素。多数正式角色和特效在 1080 画面已经放大；不支持统一缩半，因此保留现有尺寸和战斗比例。
- 表中的最大值易受细长三角形影响；面积加权 P99 也不能替代少数重要细节。UI 活动状态测量与 1440 宽外推仅用于定位候选，不作为未访问状态、任意设备或制作预览的缩图许可。

4. 缺失边缘
- 技能原稿中的锁遮住了部分圆环。按用户批准补绘缺失小段；仅拼入限定角落，主体保留。15 个技能的区域外像素比对无变化，9 个使用了局部补绘。
- 地图狼徽章去除烘焙锁的小区域，并保留独立锁状态节点；限定修复矩形之外 RGBA 差异为 0。导航书本则从原始图恢复完整边角，不用近似重画。
- 工具：内置 imagegen，编辑模式；完整提示词、来源和限制位于 ArtSources/UI/SkillRepairs/prompts.json 与 ArtSources/UI/MapRepairs/prompt.json。补绘区域属于近似修复，不宣称逐像素还原。

- 功能验证结果.csv 列出每个页面的最终状态；失败的中间轮次保存在本地 output/ui-production-audit/phase*/，不抹掉历史失败。
- 实景使用 Unity Play Mode，覆盖 9:16、3:4、1:2、相关安全区与正常/按下/禁用/恢复、折叠、奖励和返回状态。广告和支付使用测试回调，不产生真实购买。
- 修正旧验证脚本与当前功能不一致的问题：地图现为五个战斗节点及两个剧情节点；弹窗需要等待收起动画；每日提醒现在直接领取；主界面检测要隔离自动补给提示。地图导航测试用临时高血量避免测试调用隐藏的战败中返回按钮，正式战斗规则未改。
