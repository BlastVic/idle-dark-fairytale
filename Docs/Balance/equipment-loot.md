## 属性规则

武器固定攻击主属性；盾牌、头盔、护甲固定防御；饰品固定生命。每件必有一条风格属性，重武器偏攻击/暴伤，轻武器偏攻速，精准武器偏暴击；生存装备偏生命、守御偏生命比例、进攻偏攻击、增幅偏攻击比例。武器重击型基础攻击约+20%，迅捷/精准型约-10%，避免高攻速与最高攻击同时获得。

所有属性为闭区间整数随机，不沿用旧浮点抽取再截断造成的上限难出现。普通/精良/稀有/史诗/传说倍率为1/1.10/1.20/1.32/1.45，主属性及风格属性均按倍率四舍五入；额外附加属性条数为0/1/1/2/3，从该件的三个候选属性中不重复抽取。不增加新战斗机制，不改变角色武器动画。分解经验按档位为1/3/15/20/50，再乘品质倍率并四舍五入（最高72）；保留旧第三档约15、第四档20、Boss档50的回收价值，避免减少掉落量后又大幅压低单件经验。每个节点预期回收量仍因新宝箱和掉率变化而改变，不宣称融合经济与旧版完全一致。

防御仍是现有的直接减伤，故防御主值明显低于武器攻击值；高品质旧装备仍可能超过新装备，这是保留旧存档数值的兼容结果。全章自然通关率、技能组合及长期融合经济仍需持续试玩调优，随机抽样通过不等于最终平衡定稿。

## 制作与验证

修改 JSON 调整权重/属性；仅显式执行 Tools → Dark Fairytale → Balance → Apply Equipment Loot 才将来源键写入怪物 Prefab、档位写入关卡，并清除旧重复奖励。导入与运行均不改写 Prefab。原 Chapter01BalanceTools 已同步新字段并退役旧资源迁移入口，不再恢复旧掉落表。

Validate Equipment Loot 使用生产抽取代码，固定随机种子并恢复全局随机状态；检查140键完整覆盖、五类来源、属性范围、品质分布、档位隔离、Boss不重样、宝箱件数和部位、旧箱迁移。Play验证使用禁存档会话，走实际 Enemy.Drops、装备按钮、ChestPackage.TapOpen、重复点击防重和返回营地，并保存三比例截图至忽略目录 output/equipment-loot。
